# 🎮 Sims 4 Mods Catalog (WordPress Custom Theme)

Кастомный высокопроизводительный каталог модов для игры **The Sims 4**, разработанный на базе **WordPress** с использованием чистой стартовой темы и фреймворка **Bootstrap 5**.

Проект ориентирован на создание независимой, кастомной экосистемы для публикации, модерации и скачивания игрового контента (одежда, аксессуары, причёски и кастомный контент) без использования громоздких сторонних шаблонов.

---

## 🛠️ Технологический стек

* **Backend Engine:** WordPress (CMS) + PHP 8.2+
* **Database:** MySQL 8.0
* **Frontend:** Bootstrap 5 (Кастомная натяжка вёрстки)
* **Environment:** Docker / Docker Compose + WSL (Ubuntu)
* **Version Control:** Git / GitHub

---

## 📁 Архитектура и структура проекта

* `/wp-content/themes/sims4catalog/` — наша изолированная кастомная тема, написанная с нуля.
* `docker-compose.yml` — конфигурация изолированных контейнеров веб-сервера, базы данных и phpMyAdmin.
* `.env.example` — шаблон для безопасного хранения секретных ключей окружения и портов локального сервера.

---

## 🚀 Как запустить проект локально в Docker

1. Убедитесь, что у вас установлены **Docker** и **Docker Compose**.
2. Склонируйте репозиторий к себе в рабочую папку:
   ```bash
   git clone https://github.com
   cd sims4-catalog
   ```
3. Создайте локальный файл окружения `.env` из шаблона:
   ```bash
   cp .env.example .env
   ```
4. Запустите Docker-контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
   ```
5. Откройте проект в браузере:
    * **Сайт:** `http://localhost:8085`
    * **phpMyAdmin:** `http://localhost:8185`
